---

Mailpit is an email testing tool for developers. Point your app's SMTP settings at Mailpit, and every email the app sends lands in Mailpit's inbox instead of a real person's. You can then read each email in a web UI, or check it in automated tests through the REST API.

<Note>
  These are unofficial community docs for Mailpit v1.33, created by [Isaac Tony](https://github.com/isaactony). They aren't affiliated with the Mailpit project. The official docs are at [mailpit.axllent.org](https://mailpit.axllent.org/docs/). See [About these docs](/resources/about-these-docs).
</Note>

## Use Mailpit when you need to

- Send email from an app on your machine without emailing real users.
- See exactly what an email looks like: HTML, plain text, headers, attachments, and raw source.
- Assert in automated tests that an email was sent, with the right recipient and content.
- Test how your app handles SMTP errors.

## How Mailpit fits into your setup

```text
Your app ──SMTP :1025──▶ Mailpit ──▶ Web UI   http://localhost:8025
                                 └─▶ REST API http://localhost:8025/api/v1
```

| Default | Value |
| :-- | :-- |
| SMTP port your app sends to | `1025` |
| Web UI and API address | `http://localhost:8025` |
| SMTP authentication | Off |
| TLS encryption | Off |
| Storage | Temporary. Messages are deleted when Mailpit stops. |
| Messages kept | The newest 500 |

Mailpit never delivers email to real recipients unless you explicitly configure a relay. For more on the moving parts, see [How Mailpit captures email](/concepts/how-mailpit-works).
