title: "Runtime options: flags and environment variables"
description: "Every Mailpit v1.33 command-line flag with its MP_ environment variable and default, grouped by task: ports, storage, web UI, SMTP, relay, tags, and integrations."
---

Set any option as a command-line flag or as an environment variable. Environment variables are the usual choice for Docker and CI. Run `mailpit --help` to list the flags for your installed version.

```bash
# These two commands are equivalent
mailpit --max 5000 --database /data/mailpit.db
MP_MAX_MESSAGES=5000 MP_DATABASE=/data/mailpit.db mailpit
```

<Warning>
  Mailpit ignores environment variables it doesn't recognize and logs no warning. Check spelling carefully, especially in Docker Compose files.
</Warning>

Boolean flags turn on when present, such as `--enable-chaos`. For the environment variable, use `true`.

## Network and ports

| Flag | Environment variable | Default | Description |
| :-- | :-- | :-- | :-- |
| `-s`, `--smtp` | `MP_SMTP_BIND_ADDR` | `[::]:1025` | SMTP interface and port. Use `127.0.0.1:1025` to accept only local connections. |
| `-l`, `--listen` | `MP_UI_BIND_ADDR` | `[::]:8025` | Web UI and API interface and port |
| `--pop3` | `MP_POP3_BIND_ADDR` | `[::]:1110` | POP3 interface and port. POP3 starts only when `--pop3-auth-file` is set. |
| `--webroot` | `MP_WEBROOT` | `/` | Path for the web UI and API, for example `/mailpit/` behind a [reverse proxy](/guides/reverse-proxy) |
| `--label` | `MP_LABEL` | None | A name that identifies this instance. Webhooks include it as the `Mailpit-Label` header. |

## Storage and limits

| Flag | Environment variable | Default | Description |
| :-- | :-- | :-- | :-- |
| `-d`, `--database` | `MP_DATABASE` | Temporary file | Database file, or an rqlite URL such as `http://localhost:4001`. Without it, messages are deleted when Mailpit stops. |
| `-m`, `--max` | `MP_MAX_MESSAGES` | `500` | Maximum messages to keep. `0` means no limit. |
| `--max-age` | `MP_MAX_AGE` | None | Delete messages older than this, for example `36h` or `14d` |
| `--max-message-size` | `MP_MAX_MESSAGE_SIZE` | `50` | Maximum message size in MB. `0` means no limit. |
| `--compression` | `MP_COMPRESSION` | `1` | Compression level for stored messages, `0` (off) to `3` |
| `--disable-wal` | `MP_DISABLE_WAL` | `false` | Turn off SQLite write-ahead logging. Needed for NFS or Samba. |
| `--disable-auto-vacuum` | `MP_DISABLE_AUTO_VACUUM` | `false` | Stop automatic database compaction. Not recommended. |
| `--tenant-id` | `MP_TENANT_ID` | None | Isolate this instance's data in a shared database |
| `--use-message-dates` | `MP_USE_MESSAGE_DATES` | `false` | Use the email's `Date` header as the received time |
| `--ignore-duplicate-ids` | `MP_IGNORE_DUPLICATE_IDS` | `false` | Drop messages whose `Message-ID` is already stored |

## Web UI and API

| Flag | Environment variable | Default | Description |
| :-- | :-- | :-- | :-- |
| `--ui-auth-file` | `MP_UI_AUTH_FILE` | None | [Password file](/guides/protect-with-password-and-https) for the web UI and API. `MP_UI_AUTH` takes credentials directly. |
| `--ui-tls-cert`, `--ui-tls-key` | `MP_UI_TLS_CERT`, `MP_UI_TLS_KEY` | None | Certificate and key to serve HTTPS. Set both. |
| `--api-cors` | `MP_API_CORS` | Same origin only | Comma-separated origins allowed to call the API and websocket from a browser |
| `--allowed-hosts` | `MP_ALLOWED_HOSTS` | Any | Comma-separated `Host` header values to accept. Blocks DNS-rebinding attacks. |
| `--send-api-auth-file` | `MP_SEND_API_AUTH_FILE` | Web UI rules | Separate password file for `POST /api/v1/send` |
| `--send-api-auth-accept-any` | `MP_SEND_API_AUTH_ACCEPT_ANY` | `false` | Allow `POST /api/v1/send` without a login |
| `--hide-delete-all-button` | `MP_HIDE_DELETE_ALL_BUTTON` | `false` | Hide **Delete all** in the web UI |
| `--block-remote-css-and-fonts` | `MP_BLOCK_REMOTE_CSS_AND_FONTS` | `false` | Don't load remote CSS and fonts when showing messages |
| `--disable-http-compression` | `MP_DISABLE_HTTP_COMPRESSION` | `false` | Turn off gzip for the web UI and API |
| `--allow-internal-http-requests` | `MP_ALLOW_INTERNAL_HTTP_REQUESTS` | `false` | Let the link checker, HTML checker, and screenshots reach internal IP addresses |
| `--allow-untrusted-tls` | `MP_ALLOW_UNTRUSTED_TLS` | `false` | Don't verify HTTPS certificates in the link checker and screenshots |

## SMTP server

| Flag | Environment variable | Default | Description |
| :-- | :-- | :-- | :-- |
| `--smtp-auth-file` | `MP_SMTP_AUTH_FILE` | None | Password file for SMTP. `MP_SMTP_AUTH` takes credentials directly. Needs TLS unless `--smtp-auth-allow-insecure` is set. |
| `--smtp-auth-accept-any` | `MP_SMTP_AUTH_ACCEPT_ANY` | `false` | Accept any username and password, or none |
| `--smtp-auth-allow-insecure` | `MP_SMTP_AUTH_ALLOW_INSECURE` | `false` | Allow login without encryption |
| `--smtp-tls-cert`, `--smtp-tls-key` | `MP_SMTP_TLS_CERT`, `MP_SMTP_TLS_KEY` | None | Certificate and key. Turns on optional STARTTLS. |
| `--smtp-require-starttls` | `MP_SMTP_REQUIRE_STARTTLS` | `false` | Reject clients that don't use STARTTLS |
| `--smtp-require-tls` | `MP_SMTP_REQUIRE_TLS` | `false` | Use TLS from the start. Turns off STARTTLS. |
| `--smtp-max-recipients` | `MP_SMTP_MAX_RECIPIENTS` | `100` | Recipients allowed per message |
| `--smtp-allowed-recipients` | `MP_SMTP_ALLOWED_RECIPIENTS` | All | Regular expression that recipients must match |
| `--smtp-ignore-rejected-recipients` | `MP_SMTP_IGNORE_REJECTED_RECIPIENTS` | `false` | Answer rejected recipients with a `2xx` code instead of an error |
| `--smtp-strict-rfc-headers` | `MP_SMTP_STRICT_RFC_HEADERS` | `false` | Reject messages with malformed header line endings |
| `--smtp-disable-rdns` | `MP_SMTP_DISABLE_RDNS` | `false` | Skip reverse DNS lookups of clients |

## Relay and forwarding

| Flag | Environment variable | Description |
| :-- | :-- | :-- |
| `--smtp-relay-config` | `MP_SMTP_RELAY_CONFIG` | YAML file for the relay used by **Release**. Each key also has its own variable, such as `MP_SMTP_RELAY_HOST`. See [Release messages to a real SMTP server](/guides/release-to-a-real-smtp-server). |
| `--smtp-relay-all` | `MP_SMTP_RELAY_ALL` | Relay every incoming message automatically |
| `--smtp-relay-matching` | `MP_SMTP_RELAY_MATCHING` | Relay messages whose recipients match a regular expression |
| `--smtp-forward-config` | `MP_SMTP_FORWARD_CONFIG` | YAML file to forward a copy of every message to fixed addresses |

## Tags

| Flag | Environment variable | Description |
| :-- | :-- | :-- |
| `-t`, `--tag` | `MP_TAG` | Match rules, such as `invoice=subject:invoice`. See [Tags](/concepts/tags#match-rules). |
| `--tags-config` | `MP_TAGS_CONFIG` | YAML file of match rules |
| `--tags-disable` | `MP_TAGS_DISABLE` | Turn off `plus-addresses`, `x-tags`, or both (comma-separated) |
| `--tags-title-case` | `MP_TAGS_TITLE_CASE` | Capitalize new automatic tags |
| `--tags-username` | `MP_TAGS_USERNAME` | Tag messages with the authenticated username |

## Integrations

| Flag | Environment variable | Default | Description |
| :-- | :-- | :-- | :-- |
| `--webhook-url` | `MP_WEBHOOK_URL` | None | URL to call for each new message. See [Webhooks](/guides/webhooks). |
| `--webhook-limit` | `MP_WEBHOOK_LIMIT` | `1` | At most one webhook every N seconds. `0` means no limit. |
| `--webhook-delay` | `MP_WEBHOOK_DELAY` | `0` | Seconds to wait before each webhook |
| `--enable-chaos` | `MP_ENABLE_CHAOS` | `false` | Allow [Chaos](/guides/simulate-smtp-failures) triggers |
| `--chaos-triggers` | `MP_CHAOS_TRIGGERS` | None | Turn on Chaos with triggers, such as `Recipient:451:100` |
| `--enable-spamassassin` | `MP_ENABLE_SPAMASSASSIN` | None | SpamAssassin server as `<host>:<port>` |
| `--enable-rspamd` | `MP_ENABLE_RSPAMD` | None | Rspamd server URL |
| `--enable-prometheus` | `MP_ENABLE_PROMETHEUS` | `false` | `true`, or an address such as `0.0.0.0:9090` |
| `--pop3-auth-file` | `MP_POP3_AUTH_FILE` | None | Password file. Required to start the POP3 server. |
| `--pop3-tls-cert`, `--pop3-tls-key` | `MP_POP3_TLS_CERT`, `MP_POP3_TLS_KEY` | None | Certificate and key for POP3 |

## Logging and updates

| Flag | Environment variable | Default | Description |
| :-- | :-- | :-- | :-- |
| `-v`, `--verbose` | `MP_VERBOSE` | `false` | Log more detail, including each SMTP connection |
| `-q`, `--quiet` | `MP_QUIET` | `false` | Log errors only |
| `--log-file` | `MP_LOG_FILE` | Standard output | Write the log to a file |
| `--disable-version-check` | `MP_DISABLE_VERSION_CHECK` | `false` | Don't check GitHub for new releases |
